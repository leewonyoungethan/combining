# 🧬 몬스터 합치기

몬스터 레전드 스타일의 브라우저 게임이에요. 섬을 꾸미고, 몬스터를 교배하고, 키워서 턴제 전투를 해요.

▶️ 플레이: https://leewonyoungethan.github.io/combining/

## 속성
- **기본 속성 8개**: 🔥불 · 💧물 · ⚡전기 · 🌿풀 · ⛰️땅 · 🌑어둠 · ✨빛 · 🧪독
- **특수 속성 3개**: ❄️얼음(물+전기) · ⚙️금속(불+땅) · 🔮마법(빛+어둠) — 교배로만 얻어요

## 시작하기
처음엔 교배산과 부화장만 있는 빈 섬이에요. 💰2,500으로 상점에서 서식지와 몬스터 알을 사서 시작하세요!

## 게임 방법
- **🏝️ 섬 18개**: 🌳초원 · 🏜️사막 · ❄️눈 · 🌋화산 · 🌴정글 · 🌙밤 · 💎수정 · ☁️구름 · 🌸벚꽃 · 🍁가을 · 🏖️해변 · 🍭사탕 · 🍄버섯 · ⚓해적 · 🐊늪지 · 🚀우주 · 👑황금 · 🌈무지개 섬 (섬마다 25칸, 총 450칸). 위쪽 ◀ ▶ 버튼이나 🗺️ 섬 지도로 옮겨 다녀요. 지금 섬이 가득 차면 상점에서 산 서식지는 다음 섬에 지어져요.
- **🏔️ 교배산**: Lv.4 이상 몬스터 두 마리를 섞어요. 교배산을 더 지으면(💰3,000) 여러 쌍을 동시에 교배할 수 있어요. 📜 교배 기록이 남아서 🔁 버튼으로 같은 조합을 바로 다시 교배할 수 있어요. 타이머가 길게 뜰수록 높은 등급이에요 (커먼 → 레어 → 에픽 → 레전더리 → 신화). 레전더리는 세 속성 족보를 맞추면 40%, 족보를 몰라도 에픽끼리 교배하면 10%(레어끼리 4%) 확률로 나와요.
- **🪺 부화장**: 부화장을 더 지으면(💰2,000) 알을 3칸씩 더 보관해요. 🔗 부화장 두 개를 합치면 칸을 모두 합친 큰 부화장이 되고 보너스 1칸이 붙어요. 알을 부화시켜 속성이 맞는 서식지로 보내요. 레전더리 이상은 전설의 서식지에서 살아요.
- **🏠 서식지**: 몬스터가 골드를 벌어요. 한 서식지에 몬스터를 몇 마리든 넣을 수 있고, 골드도 끝없이 쌓여요. 업그레이드(최대 Lv.10)할 때마다 골드 수입이 +25%씩 올라요.
- **🌾 농장**: 작물 11종(🌱새싹 풀 30초 ~ 🌟별빛 과일 2시간)을 심어 먹이 🍖를 얻고, 몬스터에게 먹여 레벨을 올려요. 작물을 고를 때 🌾 모든 농장에 버튼으로 빈 농장 전부에 같은 작물을 한 번에 심을 수 있어요. 🧺 모두 수확, 🔁 모두 다시 재배도 있어요.
- **⚔️ 모험**: 몬스터 3마리로 턴제 전투를 해요. 속도가 빠른 몬스터가 먼저 움직이고, 스킬은 스태미나 ⚡를 써요. 공격하면 달려들어 속성 이모지를 날리고, 에너지가 0이 된 몬스터는 🪦 쓰러져요. 속성 상성이 중요해요!
- **👹 보스전**: 모험 탭에서 보스 6마리에 도전해요. 에너지가 엄청 많고, 강한 보스는 한 턴에 2~3번 움직여요. 처음 이기면 큰 보상과 다음 보스가 열려요.
- **🎁 일일 보상**: 7일 출석 보상 (7일차: 💎50 + ★★★ 룬). 하루라도 빠지면 1일차부터 다시 시작해요.
- **🎨 섬 꾸미기**: 장식 16종(🪴화분 ~ 🏰성, 👑황금 왕관 동상)을 빈 땅에 놓아요. 놓은 섬의 서식지 골드가 장식마다 1~8% 올라요 (섬마다 최대 +30%).
- **🐾 내 몬스터**: 등급·속성·섬·서식지별로 묶어 보고, 레벨·등급·이름·최근 순으로 정렬해요.
- **💠 룬**: 체력/공격/속도 룬을 몬스터에게 2개까지 끼울 수 있어요. 같은 룬 3개를 합성하면 한 단계 위 룬이 돼요.
- **🛒 상점**: 서식지·농장·교배산, 기본 몬스터 알, ❄️서리 펭귄·⚙️강철 로봇·🔮비전 고블린 알(💰500), 룬 상자, 그리고 절대 모을 수 없는 가격의 👑 전설 상점이 있어요.
- **📖 도감**: 총 500마리가 모두 보여요. 몬스터를 누르면 내 몬스터 중 가장 확률이 높은 **추천 교배 조합**을 알려 주고, 버튼 한 번에 교배산으로 가요.
