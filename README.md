# 🧬 몬스터 합치기

몬스터 두 마리를 교배산에 보내 새로운 몬스터를 만드는 브라우저 게임이에요.
`index.html`을 브라우저로 열면 바로 플레이할 수 있어요.

## 게임 방법
- **교배산**: 몬스터 두 마리를 섞어요. 타이머가 길게 뜰수록 높은 등급이에요 (커먼 → 레어 → 에픽 → 레전더리 → 신화).
- **족보**: 특정 속성을 섞으면 숨겨진 몬스터가 태어나요. 힌트는 도감에서 볼 수 있어요.
- **농장**: 토마토를 수확해서 몬스터에게 먹이면 레벨이 올라가요.
- **전투**: 몬스터 3마리로 팀을 짜서 속성 상성을 이용해 싸워요.
- **도감**: 총 62마리의 몬스터를 모아 보세요.

## 🔒 비밀코드
오른쪽 위 자물쇠 버튼을 눌러 비밀코드를 입력할 수 있어요.
