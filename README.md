# 🧬 몬스터 합치기

몬스터 레전드 스타일의 브라우저 게임이에요. 섬을 꾸미고, 몬스터를 교배하고, 키워서 턴제 전투를 해요.

▶️ 플레이: https://leewonyoungethan.github.io/combining/

## 시작하기
처음엔 교배산과 부화장만 있는 빈 섬이에요. 💰2,500으로 상점에서 서식지와 몬스터 알을 사서 시작하세요!

## 게임 방법
- **🔍 확대**: 폰에서는 두 손가락으로 벌리거나 오므려서 확대·축소해요 (PC는 마우스 휠). 섬 화면 오른쪽 ＋/− 버튼도 있어요.
- **✋ 드래그**: 건물을 꾹 눌러 끌어서 빈 땅에 놓으면 그 자리로 옮겨요. 🙈 숨기기로 이름표를 감출 수 있어요.
- **🏝️ 섬 18개**: 🌳초원 · 🏜️사막 · ❄️눈 · 🌋화산 · 🌴정글 · 🌙밤 · 💎수정 · ☁️구름 · 🌸벚꽃 · 🍁가을 · 🏖️해변 · 🍭사탕 · 🍄버섯 · ⚓해적 · 🐊늪지 · 🚀우주 · 👑황금 · 🌈무지개 섬 (섬마다 25칸, 총 450칸). 위쪽 ◀ ▶ 버튼이나 🗺️ 섬 지도로 옮겨 다녀요. 지금 섬이 가득 차면 상점에서 산 서식지는 다음 섬에 지어져요.
- **🏔️ 교배산**: Lv.4 이상 몬스터 두 마리를 섞어요. 교배산을 더 지으면(💰3,000) 여러 쌍을 동시에 교배할 수 있어요. 📜 교배 기록이 남아서 🔁 버튼으로 같은 조합을 바로 다시 교배할 수 있어요. 타이머가 길게 뜰수록 높은 등급이에요 (일반 → 정제 → 고급 → 숙련 → 희귀 → 특별 → 명품 → 영웅 → 서사 → 전설 → 신화 → 초월 → 신성 → 절대 → 근원, 15단계). 전설은 세 속성 족보를 맞추면 40%, 족보를 몰라도 서사끼리 교배하면 10%(희귀끼리 4%) 확률로 나와요.
- **🪺 부화장**: 알을 누르면 바로 깨어나요 (🐣 모두 부화로 한 번에 자동 이사도 돼요). 부화장을 더 지으면(💰2,000) 알을 3칸씩 더 보관하고. 교배는 ❌ 취소할 수 있어요 (비용 환불). (예전에 합쳐 둔 교배산·부화장은 🔓 합치기 취소로 나눌 수 있어요.) 알을 부화시켜 속성이 맞는 서식지로 보내요. 전설 이상은 전설의 서식지에서 살아요.
- **🏠 서식지**: 몬스터가 골드를 벌어요. 서식지 레벨만큼 몬스터가 들어가요 (Lv.1~2는 2마리, Lv.10은 10마리). 골드는 끝없이 쌓이고, 업그레이드(최대 Lv.10)할 때마다 골드 수입도 +25%씩 올라요.
- **🌾 농장**: 작물 11종(🌱새싹 풀 30초 ~ 🌟별빛 과일 2시간)을 심어 먹이 🍖를 얻고, 몬스터에게 먹여 레벨을 올려요. 작물을 고를 때 🌾 모든 농장에 버튼으로 빈 농장 전부에 같은 작물을 한 번에 심을 수 있어요. 🧺 모두 수확, 🔁 모두 다시 재배도 있어요.
- **⚔️ 모험**: 몬스터 3마리로 턴제 전투를 해요. 속도가 빠른 몬스터가 먼저 움직이고, 스킬은 스태미나 ⚡를 써요. 공격하면 달려들어 속성 이모지를 날리고, 에너지가 0이 된 몬스터는 🪦 쓰러져요. 속성 상성이 중요해요!
- **👥 친구 대전**: 모험 탭에서 🏠 방 만들기를 누르면 6자리 방 코드가 나와요. 친구가 🔑 코드로 들어가면 서로의 팀으로 실시간 턴제 대전을 해요 (각자 자기 몬스터 스킬을 골라요). 이기면 💰300 + 💎5. 서버 없이 브라우저끼리 바로 연결돼요 (PeerJS).
- **👹 보스전**: 모험 탭에서 보스 6마리에 도전해요. 에너지가 엄청 많고, 강한 보스는 한 턴에 2~3번 움직여요. 처음 이기면 큰 보상과 다음 보스가 열려요.
- **🎁 일일 보상**: 7일 출석 보상 (7일차: 💎50 + ★★★ 룬). 하루라도 빠지면 1일차부터 다시 시작해요.
- **🎨 섬 꾸미기**: 장식 16종(🪴화분 ~ 🏰성, 👑황금 왕관 동상)을 빈 땅에 놓아요. 놓은 섬의 서식지 골드가 장식마다 1~8% 올라요 (섬마다 최대 +30%).
- **🐾 내 몬스터**: 등급·속성·섬·서식지별로 묶어 보고, 레벨·등급·이름·최근 순으로 정렬해요. 💸 겹치는 몬스터 팔기로 같은 종류는 가장 레벨이 높은 한 마리(와 모험 팀)만 남기고 한 번에 팔 수 있어요.
- **💠 룬**: 체력/공격/속도 룬을 몬스터에게 2개까지 끼울 수 있어요. 같은 룬 3개를 합성하면 한 단계 위 룬이 돼요.
- **🛒 상점**: 서식지·농장·교배산, 기본 몬스터 알, ❄️서리 펭귄·⚙️강철 로봇·🔮비전 고블린 알(💰500), 룬 상자, 그리고 절대 모을 수 없는 가격의 👑 전설 상점이 있어요. 전설 상점 몬스터(초월~근원)는 전설 이상끼리 교배해도 아주 드물게 나와요 (예: 전설+전설 → 초월 2%, 신화+신화 → 초월 8%).
- **📖 도감**: 총 2000마리가 모두 보여요 (속성마다 31마리, 두 속성 조합마다 29마리, 전설 34마리, 신화 25마리, 전설 상점 5마리). 등급은 피라미드 모양이라 일반 : 신화가 약 20 : 1이에요 (일반 538 · 정제 397 · 고급 290 · 숙련 218 · 희귀 167 · 특별 122 · 명품 83 · 영웅 66 · 서사 55 · 전설 34 · 신화 25). 신화는 전설끼리 교배하면 나오고, 부모와 속성이 많이 겹치는 신화일수록 잘 나와요. 몬스터를 누르면 내 몬스터 중 가장 확률이 높은 **추천 교배 조합**을 알려 주고, 버튼 한 번에 교배산으로 가요.
