# 🧬 몬스터 합치기

몬스터 레전드 스타일의 브라우저 게임이에요. 섬을 꾸미고, 몬스터를 교배하고, 키워서 턴제 전투를 해요.

▶️ 플레이: https://leewonyoungethan.github.io/combining/

## 속성
- **기본 속성 8개**: 🔥불 · 💧물 · ⚡전기 · 🌿풀 · ⛰️땅 · 🌑어둠 · ✨빛 · 🧪독
- **특수 속성 3개**: ❄️얼음(물+전기) · ⚙️금속(불+땅) · 🔮마법(빛+어둠) — 교배로만 얻어요

## 시작하기
처음엔 교배산과 부화장만 있는 빈 섬이에요. 💰2,500으로 상점에서 서식지와 몬스터 알을 사서 시작하세요!

## 게임 방법
- **🏝️ 섬**: 교배산, 부화장, 농장, 서식지가 있어요. 빈 땅에 새 서식지나 농장을 지을 수 있어요.
- **🏔️ 교배산**: Lv.4 이상 몬스터 두 마리를 섞어요. 타이머가 길게 뜰수록 높은 등급이에요 (커먼 → 레어 → 에픽 → 레전더리 → 신화).
- **🪺 부화장**: 알을 부화시켜 속성이 맞는 서식지로 보내요. 레전더리 이상은 전설의 서식지에서 살아요.
- **🏠 서식지**: 몬스터가 골드를 벌어요. 업그레이드하면 더 많은 몬스터가 살 수 있어요.
- **🌾 농장**: 작물을 심어 먹이 🍖를 얻고, 몬스터에게 먹여 레벨을 올려요. 🧺 모두 수확, 🔁 모두 다시 재배(모든 농장에 지난번 작물을 다시 심기)도 있어요.
- **⚔️ 모험**: 몬스터 3마리로 턴제 전투를 해요. 속도가 빠른 몬스터가 먼저 움직이고, 스킬은 스태미나 ⚡를 써요. 공격하면 달려들어 속성 이모지를 날리고, 에너지가 0이 된 몬스터는 🪦 쓰러져요. 속성 상성이 중요해요!
- **👹 보스전**: 모험 탭에서 보스 6마리에 도전해요. 에너지가 엄청 많고, 강한 보스는 한 턴에 2~3번 움직여요. 처음 이기면 큰 보상과 다음 보스가 열려요.
- **🎁 일일 보상**: 7일 출석 보상 (7일차: 💎50 + ★★★ 룬). 하루라도 빠지면 1일차부터 다시 시작해요.
- **💠 룬**: 체력/공격/속도 룬을 몬스터에게 2개까지 끼울 수 있어요. 같은 룬 3개를 합성하면 한 단계 위 룬이 돼요.
- **🛒 상점**: 서식지·농장, 기본 몬스터 알, 룬 상자, 그리고 절대 모을 수 없는 가격의 👑 전설 상점이 있어요.
- **📖 도감**: 총 500마리가 모두 보여요. 몬스터를 누르면 내 몬스터 중 가장 확률이 높은 **추천 교배 조합**을 알려 주고, 버튼 한 번에 교배산으로 가요.
